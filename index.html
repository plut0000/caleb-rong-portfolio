SignSpeak

A proof of concept that reads American Sign Language from a webcam, then shows the English translation and reads it aloud. Landmarks are extracted in the browser and classified by a BiLSTM model running on ONNX Runtime.

  • Next.js
  • TypeScript
  • MediaPipe
  • ONNX Runtime
  • Gemini

Locus

Drop in a photo and Locus places it on a map. It reads embedded GPS data first, falls back to a vision model when there isn't any, and shows an uncertainty radius instead of a single exact pin.

About

I like starting with a simple question, "could this be a little easier?", and building until there's something people can actually use.

My recent projects explore that question in accessibility, discovery and learning. I care about tools that are honest about what they can't do: SignSpeak reports how confident it is, and Locus shows an uncertainty radius instead of claiming an exact spot.

Everything here is open source, so you can read the code behind each project.
