Projects

SignSpeak

  • Live demo
  • Source

ASL-to-English translation in the browser.

A proof of concept that reads American Sign Language from a webcam, then shows the English translation and reads it aloud.

  • MediaPipe extracts pose and hand landmarks from the recording in the browser.
  • Short, isolated signs go through a 200-class BiLSTM model on ONNX Runtime, and Gemini cleans up the prediction. Longer clips fall back to video analysis.
  • The result shows the translation, a confidence score and which model path was used. It can be read aloud with the Web Speech API.

It handles isolated signs and is a feasibility test, not an interpreter.

Next.js · TypeScript · MediaPipe · ONNX Runtime · Gemini · Web Speech API

Locus

  • Source

Estimates where a photo was taken.

Upload a photo and Locus places it on a map. It checks the file's metadata first and only guesses from visual clues when there's no GPS data.

  • Reads EXIF GPS coordinates in the browser, converting HEIC files when it can.
  • Without GPS data, a server-side vision model estimates a location from architecture, signs and terrain.
  • The result appears on a Leaflet map with the model's reasoning and an uncertainty radius instead of a single exact pin.

EXIF lookup works without an API key. Visual guesses need an AI provider configured on the server.

Vite · React · TypeScript · Leaflet · exifr · Express

Cognify

  • Live app
  • Source

Study tools generated from your own notes.

Upload your notes and Cognify turns them into study material. A chat assistant answers questions using the same notebook.

  • Upload PDF, TXT or Markdown files and organize them into notebooks.
  • Generate summaries, flashcard decks, practice quizzes at a chosen difficulty, and slide decks with speaker notes.
  • Ask a Gemini-based study coach questions. Its answers come from the notebook's contents.

Sign-in uses Google through Auth.js.

Next.js · TypeScript · Gemini · PDF.js · Auth.js

About

Each of these projects started with the same question: could this be a little easier? I like work that sits between a useful model and an interface people can actually use.

I also care about tools being honest about their limits. That's why SignSpeak shows its confidence and Locus draws a radius instead of claiming an exact spot.

I post new work on GitHub.
